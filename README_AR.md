# Beauty Store Marrakech — متجر تجميل باستخدام Python

## المتطلبات
- Python 3
- اتصال بالإنترنت لتحميل صور المنتجات والخطوط الخارجية

## التشغيل على Windows
1. فك ضغط الملف.
2. افتح مجلد `beauty_store_marrakech` في VS Code.
3. افتح Terminal داخل VS Code.
4. نفّذ:
   ```bash
   py -m pip install -r requirements.txt
   py app.py
   ```
5. افتح المتصفح على: http://127.0.0.1:5000

إذا لم يعمل الأمر `py` جرّب `python` بدلاً منه.

## تعديل الموقع
- المنتجات والأسعار وروابط الصور موجودة في أعلى `app.py` داخل القائمة `PRODUCTS`.
- قبل استقبال الطلبات، غيّر `whatsapp_number` في `app.py` إلى رقم واتساب متجرك بصيغة دولية، أرقام فقط، من دون `+` أو مسافات.
- غيّر `app.secret_key` إلى قيمة عشوائية خاصة بك قبل النشر.
- الصور مستضافة على Unsplash وتحتاج إلى الإنترنت؛ استبدل الروابط بصور منتجاتك الحقيقية عند تجهيز المتجر.

## ملاحظات مهمة
- السلة تعمل داخل جلسة المتصفح.
- زر الطلب يرسل تفاصيل السلة إلى واتساب بعد ضبط رقم المتجر.
- لا توجد بوابة دفع إلكتروني أو لوحة إدارة أو قاعدة بيانات في هذه النسخة التجريبية.
- لا تستخدم خادم Flask التطويري للنشر العام. قبل نشر المتجر، استخدم استضافة مناسبة وإعدادات أمان وإدارة طلبات.
